# No-Pass Time runs only on a schedule, plus a manual button

Teachers asked for no passes in the first and last minutes of class, which only
means something once the app knows when each class starts and ends. So
No-Pass Time now lives in each Schedule — "first N minutes" and "last N
minutes" of its periods, plus fixed times drawn on it — and applies only while
the teacher is On Schedule. Off schedule, the teacher starts and ends a
No-Pass Time by hand from the laptop. We chose this over keeping clock times
on each class, which still applied off schedule, because a teacher who breaks
the schedule for one odd morning has deliberately taken charge of the door, and
rules timed to periods that are no longer running would be guesses.

## Consequences

- The per-class no-pass times in class settings are gone. Teachers who had
  them find them as fixed times on their first schedule, and are told so once
  in "What's changed". Each copied time now applies to whichever class the
  schedule puts on the kiosk then, not only the class it came from.
- A teacher with no schedule, or off schedule, has no automatic No-Pass Time
  at all.
